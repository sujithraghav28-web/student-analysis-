## 🎓 Student Performance Analysis & Machine Learning Predictor

### Description
A Machine Learning and Exploratory Data Analysis (EDA) project that predicts students' final academic performance (G3) based on study habits, previous grades, attendance, and past failures. The project combines statistical analysis, interactive visualizations, and a Random Forest Regressor model deployed as a Streamlit web application.

### Tech Stack
- Python
- Pandas
- Scikit-learn (Random Forest Regressor)
- Matplotlib
- Seaborn
- Streamlit

### Key Features
- Exploratory Data Analysis (EDA)
- Feature correlation heatmap
- Student performance visualization
- Random Forest Regression model
- Interactive prediction using sliders
- Model evaluation using R² Score
- Real-time grade prediction through a Streamlit web app
